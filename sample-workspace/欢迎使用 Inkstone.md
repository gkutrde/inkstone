# 欢迎使用 Inkstone

Inkstone 是一个本地优先的 Markdown 写作工作台。它把文件、笔记与排版留在同一张安静的纸面上。

## 今天可以试着做这些

- 在左侧打开一个文件夹
- 用 `Ctrl+N` 新建文稿
- 用 `Ctrl+S` 保存到本地
- 用 `Ctrl+E` 在所见即所得与 Markdown 源码之间切换

> 写作不是把世界解释清楚，而是让某一刻停下来。
